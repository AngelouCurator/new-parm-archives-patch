# Grandia: Digital Museum — English Translation Patch

A fan translation of *Grandia: Digital Museum* (Sega Saturn, Japan-only) from Japanese to English.

**Current release: `alpha-0.1.0`.** See **[RELEASE-NOTES.md](RELEASE-NOTES.md)** and
**[KNOWN-ISSUES.md](KNOWN-ISSUES.md)**.

## Motivation

This is a passion project with the primary goal of finally playing my personal Grandia Digital
Museum backup in English on a Superstation One. Sharing it in case it lets you do the same.
**Happy gaming!** 🎮

I had a secondary goal of a toy AI learning experiment where I explore an agent-driven emulator
harness and validation loop (having an AI agent reverse-engineer disc/text formats, inject text,
and verify its own work in an emulator loop). This was surprisingly effective.

## High-level technical approach

The translation was built with custom tooling and an AI-assisted workflow:

1. **Extract and prepare text** — extract the Japanese text, build a consistent terminology
   dictionary, and prepare the translated strings.
2. **Translate and reinject** — translate and review text scene by scene, then rebuild game tables,
   fonts, and text boxes to accommodate English text.
3. **Validate in-game** — use a headless YMIR emulator harness with savestates to find and iterate
   on text, graphical, and stability issues.

## What's in here

Just the patch — instructions plus the patch files themselves. **No game data is included.** This
repo deliberately ships no disc image, no game text, and no copyrighted assets. You must supply
your own dump of the Japanese *Digital Museum* disc.

| File | What it is |
| --- | --- |
| `Grandia-DM-EN-alpha-0.1.0.ssp` | **Sega Saturn Patcher** patch — the preferred format. |
| `Grandia-DM-EN-alpha-0.1.0.Track1.xdelta3` | **xdelta3** binary delta against Track 1 — the fallback format. |

The build pipeline that produces these lives in a separate repo:
**[new-parm-archives-tools](https://github.com/AngelouCurator/new-parm-archives-tools)**.

## Source disc (Redump)

The patch is built against the **Redump** dump of the Japanese disc. Nothing else will work.

|  |  |
| --- | --- |
| **Redump disc name** | `Grandia - Digital Museum (Japan) (Rev A) (10M)` |
| **Track you patch** | `Grandia - Digital Museum (Japan) (Rev A) (10M) (Track 1).bin` |
| **Track format** | `MODE1/2352` (raw 2352-byte sectors) |
| **Track 1 size** | 455,394,240 bytes (193,620 sectors) |
| **Track 1 MD5** | `59b19105615ca37886e1e0542ff2967e` |
| **Track 2 MD5** | `03b644cc286bc57840e99cf5904cb2f8` *(audio — never modified)* |

This is a **2-track disc**: Track 1 is the MODE1 data track, Track 2 is CD-DA audio. The patch only
ever touches Track 1; your Track 2 is copied through untouched.

Verify before you start:

```bash
md5 "Grandia - Digital Museum (Japan) (Rev A) (10M) (Track 1).bin"   # macOS
md5sum "Grandia - Digital Museum (Japan) (Rev A) (10M) (Track 1).bin" # Linux
# expected: 59b19105615ca37886e1e0542ff2967e
```

If your MD5 doesn't match, you have a different dump (or a bad one) and the patch will not apply.

## Applying the patch

Use [Sega Saturn Patcher](https://segaxtreme.net/resources/sega-saturn-patcher.73/) and the
`Grandia-DM-EN-alpha-0.1.0.ssp` file:

1. Select the `.cue` file for your unmodified Redump disc.
2. Select `Grandia-DM-EN-alpha-0.1.0.ssp` as the patch file.
3. Enable **Separate Track Files**, then choose where to save the patched image.
4. Click **Patch** and load the resulting `.cue` file in your emulator, ODE, or burning software.

The `.xdelta3` file is included only as an advanced fallback for users who prefer that format.

## Known limitations & untested areas

This is a work in progress. Full list in **[KNOWN-ISSUES.md](KNOWN-ISSUES.md)**. The short version —
**a savestate near any of these is especially helpful** if you hit a problem:

- **Minigames** — not all unlocked in my saves, so translated text in later ones may not have been
  seen in-game yet.
- **The Theater** — not fully unlocked either; some captions may be untranslated or **off-timed**.
- **Crashes** — expect some. ⚠️ **I'm not responsible for any save corruption, lost progress, or
  other issues that result from using this patch — use it at your own risk.** That said, **crash
  reports are genuinely useful** and I do look at them (a savestate from just before the crash is
  gold).
- **Untranslated pockets** — a few menus/areas are still Japanese.

## Reporting issues

Bug reports are very welcome. **[→ Open a new issue](../../issues/new/choose)** — it opens a short
form that walks you through it. The four things that help most:

- 💾 **A savestate** taken right at the failing spot, from whichever emulator you use.
  ⚠️ GitHub won't accept a raw `.savestate` — **zip it first**, then attach the `.zip`.
- 🕹️ **Which emulator** (and version) the savestate is from — each emulator's state format differs,
  so this is essential for me to load it.
- 📷 **A screenshot** of the problem.
- 📝 **A description**: what you expected vs. what you actually saw, where it happened, and the
  patch version (the `rcNN` in the filename).

Clear, specific, reproducible reports get fixed fastest. Thank you for helping make this project
better.
