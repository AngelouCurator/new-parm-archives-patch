# Known issues and release-candidate notes

Alpha-0.2.0 has the outstanding issues below which I'll get to when life is less busy.

- During battle an arrow shows up for some spells in bottom left such as Fiora.
- Battle level-up messages and counter notifications are still untranslated.
- On SuperStation One, the Garlyle Base background can appear jumpy. This has not been observed in
  Ymir and will be investigated.
- A few deferred theater cosmetics: caption/title-card overlap in unusual timings, a right-edge glyph in one E804 scene, and the theater-plate starfield treatment.
- Only the Redump Rev A 10M Track 1 identified in `README.md` is supported.

Please file any new issue with the patch version, emulator or hardware, a screenshot, reproduction
steps, and—when possible—a zipped savestate from immediately before the problem.
